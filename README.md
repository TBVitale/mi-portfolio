# Portfolio — Tobias Vitale

Portfolio personal de Tobias Vitale, estudiante de Análisis de Sistemas y frontend developer junior.

## Demo en vivo

[tvitale-portfolio.netlify.app](https://tvitale-portfolio.netlify.app/)

## Stack

- React 19
- Vite
- Tailwind CSS 4

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

El resultado queda en la carpeta `dist/`, lista para desplegar en Netlify u otro hosting estático.

## Secciones

- Hero con presentación y CV
- Sobre mí
- Skills (frontend, backend y herramientas)
- Proyectos con demo y enlace al código
- Contacto (email, LinkedIn, GitHub)
